ezAuth

Simple auth, user data, and storage for modern applications.

Pricing: $1/K users/month.

Custom table storage above 1GB is billed at $1/GB/month.

  • Simple by default: one API, one dashboard, and one clean integration path
  • Email/password, magic links, and 6-digit verification codes
  • Google and Apple OAuth, plus bot authentication (Ed25519)
  • Multi-tenant architecture with per-app users, keys, and domains
  • JWT sessions, refresh tokens, and public JWKS verification
  • Cross-domain SSO for seamless sign-in across related apps
  • Programmable custom tables for typed, user-scoped data
  • S3-compatible object storage with user-level isolation
  • Built-in anti-abuse protection: hashcash + rate limits
  • SDKs for JavaScript, Python, Swift, and Kotlin, plus CLI tooling
